# ENDER CLIENT

A client-side Minecraft Java utility client for Fabric 26.1.

## Current scope

This project focuses on visual and quality-of-life modules: a configurable HUD, FPS display, coordinates, keystrokes, and sprint assistance. It does not include automated combat, weapon-use automation, or anti-cheat bypass features.

## Build

- Minecraft Java 26.1
- Java 25
- Fabric Loader 0.18.4+
- Fabric API 0.142.3+26.1
- Fabric Loom 1.15+

Run `./gradlew build`. The mod JAR is written to `build/libs/`.

## Keybinds

- Right Shift: open the client menu
- The menu lets you toggle the available HUD modules.

Not an official Minecraft product. Not approved by or associated with Mojang.
